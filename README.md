# Vorreni — Shopify Horizon storefront

Herenmode-storefront (jassen, knitwear, broeken, basics) gebouwd bovenop het
Shopify **Horizon** theme.

Deze commit is de ongewijzigde Horizon-baseline uit de theme-export van
vorreni.com. Alle Vorreni-specifieke code komt in volgende commits en draagt
de prefix `vrn-`.

Zie de volledige admin-setup (kortingscodes, metafields, menu's, collecties)
verderop in dit bestand zodra de bouw af is.
