# Vorreni — Shopify Theme

Generated by Themr (https://themr.ai)

## Installation

1. Go to your Shopify Admin
2. Navigate to **Online Store > Themes**
3. Click **Add theme > Upload ZIP file**
4. Select this ZIP file
5. Click **Customize** to adjust settings

## No Shopify store yet?

## Theme Structure

- `layout/` — Main theme layout (theme.liquid)
- `templates/` — Page templates (JSON format, Shopify 2.0)
- `sections/` — Reusable sections for the theme editor
- `assets/` — CSS and other static assets
- `config/` — Theme settings schema and defaults
